# Domolan Balance — интеграция для Home Assistant

Неофициальная интеграция для Home Assistant, которая логинится в личный
кабинет интернет-провайдера [domolan.ru](https://domolan.ru/lk/login) и
раз в N минут публикует сенсор с текущим балансом лицевого счёта.

> ⚠️ Это реверс-инжиниринг публичного (незадокументированного) API сайта.
> Провайдер может изменить его в любой момент без предупреждения — тогда
> интеграция перестанет работать до обновления. Используйте на свой риск,
> храните пароль так же бережно, как в браузере.

## Что делает интеграция

1. `GET /csrf-token` — получает CSRF-токен и сессионную cookie `sails.sid`.
2. `POST /api/login` — логинится логином/паролем (с заголовком
   `X-Csrf-Token`), получает ID пользователя.
3. `GET /api/user/data` — забирает данные ЛК, в том числе поле `balance`.

Сессия (`sails.sid`) живёт ~30 дней, поэтому повторный логин выполняется
только когда она истекает или становится невалидной (ответ `401`) — в
остальное время интеграция просто опрашивает `/api/user/data`.

Вся эта логика найдена в публичном JS-бандле сайта
(`index-*.js`/`store-*.js`, минифицированный Vite/Vue билд), который
отдаётся анонимно любому посетителю — учётные данные для этого не
требовались.

## Установка

### Вручную

Скопируйте папку `custom_components/domolan_balance` в
`<config>/custom_components/domolan_balance` вашего Home Assistant и
перезапустите HA.

### Через HACS

Добавьте этот репозиторий как **Custom repository** (тип *Integration*) в
HACS, затем установите «Domolan Balance» и перезапустите HA.

## Настройка

**Настройки → Устройства и службы → Добавить интеграцию → Domolan
Balance**, затем укажите логин и пароль от личного кабинета domolan.ru.

Интервал опроса (по умолчанию 30 минут) можно поменять в настройках
интеграции (шестерёнка → **Настроить**).

Появятся 4 сенсора (объединены в одно устройство «Домолан (логин)»):

| Сенсор | Что показывает | Атрибуты |
| - | - | - |
| **Баланс** (`sensor.<логин>_balance`) | текущий баланс, ₽ | `login`, `tariff_id`, `blocked_by_low_balance`, `block_type`, `credit_by_user` |
| **Хватит на** (`sensor.<логин>_days_remaining`) | дней до блокировки за низкий баланс (`daysBeforeBlock` из ЛК) | — |
| **Тариф** (`sensor.<логин>_tariff`) | название текущего тарифа | `tariff_id`, `price` (₽/мес), `active_since` |
| **Скорость** (`sensor.<логин>_speed`) | текущая эффективная скорость, Мбит/с | `next_speed`, `current_traffic_limit`, `monthly_traffic_gb` |

## Устранение неполадок

- **Invalid login or password** при добавлении — проверьте логин/пароль
  на [domolan.ru/lk/login](https://domolan.ru/lk/login) в браузере.
- Если пароль поменяли на сайте, HA предложит повторную авторизацию
  (reauth) для этой интеграции.
- Если сайт изменит API (маршруты `/csrf-token`, `/api/login`,
  `/api/user/data` или формат ответов), интеграция перестанет получать
  данные — нужно будет обновить [`api.py`](custom_components/domolan_balance/api.py) под новую версию сайта.
